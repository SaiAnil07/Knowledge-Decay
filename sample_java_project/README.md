# Sample Knowledge Service

A microservice providing user management, order processing, and payment services.

## System Requirements
- Requirements: Java 11
- Maven 3.8+ or higher
- Port 8080 open

## Key Endpoints Overview

| Method | Endpoint | Description |
|---|---|---|
| GET | `/api/v1/users` | List all users |
| GET | `/api/v1/orders` | Create or submit an order |

See `docs/API_DOCUMENTATION.md` for full contract details.
